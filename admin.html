PANDUAN PRAKTIS & TINDAKAN PREVENTIF JIKA KUOTA MENDEKATI BATAS (THRESHOLD GUIDE)
1. Jika Database Supabase Mendekati 80% (400 MB):
Buka tab Riwayat di portal dan klik tombol "Purge Activity Logs > 90 Hari". File-file task lama yang sudah diarsipkan dapat diekspor ke format CSV sehingga ukuran storage Postgres tetap ramping di bawah 50 MB.
2. Jika Kuota Email Resend Mendekati 2.500 / Bulan:
Notifikasi task otomatis dapat diatur menjadi mode Digest (1 email ringkasan per hari per PIC) daripada mengirimkan email setiap perubahan status task satuan.
3. Jika Bandwidth ImageKit Mendekati 20 GB:
Seluruh gambar dokumentasi & kuitansi yang diunggah sudah otomatis terkonversi ke format WebP terkompresi sebelum diunggah, menghemat 80% kuota transfer data CDN secara instan.
4. Jika Bandwidth Vercel Mendekati 80 GB:
Seluruh aset statis CSS, JS, dan ikon vektor di-cache oleh browser via header Cache-Control: max-age=31536000 sehingga pengunjung yang kembali tidak mengunduh ulang aset statis.
