Petunjuk Pengambilan & Penamaan File

1. Pencahayaan & Kualitas

Gunakan kamera HP resolusi tinggi dengan pencahayaan alami/terang. Pastikan lensa bersih sebelum memotret.

2. Penamaan File yang Rapi

Beri nama file deskriptif, contoh: makan_gratis_01.jpg, fasad_siang_01.jpg, santri_tahfidz_01.jpg.

3. Upload ke Folder GDrive

Pilih folder Foto atau Video di atas, lalu unggah file asli (tanpa kompresi WA agar kualitas tetap tajam).
